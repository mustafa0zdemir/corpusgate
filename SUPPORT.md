# Support

Use these channels according to the problem:

- Usage question or proposal: GitHub Discussions, when enabled.
- Reproducible bug: GitHub issue with sanitized logs and `./corpusgate doctor` output.
- Security vulnerability: private reporting described in [SECURITY.md](SECURITY.md).

Before requesting support, use the latest release, read the troubleshooting documentation, run
`./corpusgate doctor`, and reproduce with synthetic data. Never post `.env`, Bearer/API tokens, real
document content, private hostnames, public IPs, or full filesystem paths.

This community project provides no guaranteed response time or commercial support SLA.
