# Private Network Guide

This is synthetic, non-sensitive demonstration content for CorpusGate.

## Access policy

The document service listens on loopback. Remote users connect through the private network and
authenticate with a Bearer token. The application port is not opened directly to the internet.

## Recovery

Documents are the primary data source. Operators create a backup before updates and verify the
health, ready, and MCP tool-list checks after restart.
